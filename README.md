# ALU Web Development

This repository holds my web development / systems projects for the ALU
Software Engineering program. Each project lives in its own top-level
directory with its own `README.md`, tasks, and (where required) test/main
files.

## Projects

| Directory | Project |
| --- | --- |
| [`caching`](./caching) | Caching algorithms: FIFO, LIFO, LRU, and MRU replacement policies |
| [`Basic_authentication`](./Basic_authentication) | Basic Authentication on a Flask API: error handlers, Base64 decoding, credential parsing, and user lookup |

More projects will be added here as new directories as the program progresses.

## Conventions
- Python files target Python 3.7 on Ubuntu 18.04 LTS, follow `pycodestyle`, and are executable.
- Solution files start with `#!/usr/bin/env python3`; platform-provided parent classes and main test files keep their original shebang as given.
- Every module, class, and function is documented with a real docstring.
- Each project directory contains its own `README.md` with task-specific details.
